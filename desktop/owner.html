    Агент тоже может явно сохранить новую запись в Vault. Такие записи отмечены источником и задачей; список обновляется во время работы. Временные переменные команд автоматически не сохраняются.

      Выберите JSON-профиль cc-backend. Перенесём только имя, модель, адрес и формат API в форму выше. Ключ введите отдельно; команды, MCP, переменные окружения и внешние учётные записи не переносятся. Исходный файл останется на месте.

      Доступ MCP по профилям

      У сред разные подключения и права. На карточках показано, каким моделям разрешён доступ; настройка — в меню ⋮.

      Подключения MCP

      Загрузите подключения выбранной среды.

      Настройка Gmail

      Gmail — только чтение

      Нужен Google OAuth client типа Desktop app с включённым Gmail API. Пароль Google вводится только в системном браузере. Разрешение Gmail readonly охватывает ящик целиком; отправка, удаление, изменение писем и скачивание вложений не поддерживаются. Для нового аккаунта сначала отключите прежний.

      Для переноса Gmail сначала введите пароль Vault этого desktop. Проверить состояние можно без повторного ввода пароля.

      Права доступа моделей

      Кому разрешены подключения

      Каждому подключению можно разрешить доступ отдельным профилям. По умолчанию доступ запрещён. Изменение адреса или параметров профиля требует нового разрешения.

      Режим «Только локальная обработка» работает в отдельной MCP-задаче через «+» в чате или в форме ниже. Обычный агент не получает этот доступ. Обычное разрешение может передать результаты выбранной модели, включая облачную. Права MCP не ограничивают произвольные команды того же пользователя ОС.

      Отдельная задача MCP

      Отдельная обработка MCP

      Использует выбранные выше MCP и проверенный профиль с форматом OpenAI. При доступе «Только локальная обработка» разрешён только локальный адрес модели; обычное разрешение допускает отправку выбранной облачной модели. Контекст не сохраняется в общую историю и не передаётся в обычный чат. Доступны только инструменты выбранного MCP, без файловых и командных инструментов Игорька. Каждый запрос начинает новую сессию. Доверяйте только известным MCP и серверу модели.

      Режим выполнения
      
      
      
      
      Читаю выбранный режим…
      
      
      Режим меняется при открытом хранилище и остановленном исполнителе. Он применяется при следующем запуске. Если выбран KVM, ошибка образа или виртуализации остановит задачу: перехода к выполнению на этом компьютере не будет.
      
      
      Дополнительно: образ KVM
      
      Образ для изолированного режима
      
      
      Установленный пакет образа найдётся автоматически. Если пакета нет, выберите готовый файл .qcow2 с файлом .manifest.json рядом. Проверим версию и целостность и сохраним отдельную копию для desktop. Исходный образ не меняется.
      
      
      
      
      Для подготовки откройте хранилище и остановите исполнитель.
      
      
      Подготовка может занять несколько минут. Можно вернуться в чат: операция продолжится, пока приложение открыто. Не закрывайте приложение до окончания. После подготовки выберите KVM и запустите проверенный профиль. Успешный запуск самого исполнителя ещё не подтверждает работу задачи в госте.
      
      
      
    
      

    
      
      
      Проверка компьютера
      
      
      Проверим систему, доступ к каталогу данных, память, диск и компоненты виртуализации. Проверка ничего не устанавливает, не меняет настройки, не читает ключи и не запускает модель или ВМ.
      
      
      
      
      
      
      
      
      
      Компоненты KVM нужны для выбранного изолированного режима. Без него задачи выполняются на этом компьютере. Минимальные требования по памяти и диску ещё измеряются; этот отчёт не подтверждает полную готовность приложения.
      
    
      

    
      
      
      Первое рабочее место
      
      
      Выберите отдельную папку для знакомства. Игорёк может менять файлы в выбранной папке. В режиме без KVM папка не является защитной границей доступа; в KVM она передаётся в виртуальную машину.
      
      
      
      Папка пока не выбрана.
      
      
      
      Сначала запустите профиль. В чате откроется форма новой сессии с выбранной папкой. После создания появится пример задания: создать небольшой Markdown-файл и прочитать его. Запрос начнётся только после нажатия «Отправить»; пример можно изменить или удалить. Если появится запрос записи файла, проверьте путь и нажмите «Разрешить», чтобы продолжить.
      
      
      
    
      

    
      
      
      Мобильные устройстваПрофиль и инструменты этого десктопного Игорька
      
      
      Запустите нужный профиль в разделе «Основная модель». На телефоне: настройки → Подключить по QR-коду. Повторный вход в ChatGPT не нужен.
      
      
      
        Адрес и порт подключения
        
      
        
      Для доступа с работы укажите статический IP или домен и внешний порт роутера. Этот адрес попадёт в QR. В роутере внешний TCP-порт должен вести на порт этого ПК, разрешённый в firewall. Пустой адрес — подключение по домашней сети.
      
      
      
      
      
      
      
    
      

    
      
      
      Места храненияНастройки, ключи, история и рабочие файлы
      
      
      Что хранится на этом компьютере
      Это места хранения отдельного десктопного экземпляра на этом компьютере. Данные рабочей установки Игорька не перенесены сюда автоматически.
      

      
      Ключи API-подключений зашифрованы в Vault. История чатов, файлы, журналы и настройки профилей не входят в копию восстановления ключей. Файлы задачи находятся в папке выбранной сессии; папка по умолчанию указана отдельно.
      
      
      
      
      
    
      

    
      
      
      Пароль и блокировка
      
      
      Необязательная блокировка закрывает настройки и оставляет задачу работать. По умолчанию выключена. Для защиты всего компьютера используйте блокировку Ubuntu.
      
      
      
        
        
        
      
      
      
      
      
      
      Быстрый доступ по PIN
      
      
      Шесть цифр открывают только заблокированное окно настройки до полного закрытия приложения. При новом запуске, просмотре ключей и восстановлении нужен полный пароль Vault.
      
      
      
      
      
        
        
        
        
        
      
      
      
      
      
      Сменить пароль хранилища
      
      
      Сначала остановите исполнитель. Старый пароль будет заменён новым; ключи и подключения сохранятся. Отдельная копия восстановления продолжит открываться своей фразой.
      
      
      
        
        
        
        
      
      
      
      
    
      

    
      
      
      Уже есть копия?
      
      
      Восстановите ключи из файла вместо создания пустого хранилища. Нужны фраза от копии и новый пароль. Старый пароль не требуется.
      
      
      Восстановление доступно только до создания хранилища. Чаты и остальные настройки приложения в копию ключей не входят.
      
      
      
        
        
        
        
      
      
    
      

    
      
      
      Копия восстановления
      
      
      Копия содержит ключи, их описания и сохранённые подключения моделей. История чатов и остальные настройки приложения в неё не входят. Обновляйте копию после изменения ключей или подключения.
      
      
      Сохраните файл и отдельную фразу в разных местах. Вместе они позволяют восстановить ключи без старого пароля.
      
      
      Шаг 1 из 2. Подготовьте фразу и сохраните её отдельно.
      
      
      
        
        
      
          
      Создайте случайную фразу или введите свою. Сохраните её в менеджере паролей либо другом отдельном месте: приложение не сможет напомнить эту фразу.
      
          
          
        
      
        
      
          Шаг 2. Подтвердите фразу и сохраните файл
          
      Повторите фразу из места, куда вы её сохранили. Затем введите пароль хранилища и выберите место для файла. Приложение сразу проверит восстановление из сохранённого файла.
      
          
          
          
          
          
        
      
      
      
    
      

    
      
      
      Проверить имеющуюся копию
      
      
      Выберите файл и введите его фразу. Проверка пробует восстановить ключи во временное хранилище. Текущий Vault не меняется.
      
      
      
        
        
      
      
    
      

    
      
    
      При каждом открытии разблокируйте хранилище и запустите нужный профиль. Режим выполнения выбирается в разделе «Среда выполнения». Во время задачи сначала дождитесь её завершения или отмените её в чате.

        Перенести секреты и переменные
        
    
        
    
        Выбери записи и их тип. Значения скрыты и будут зашифрованы в Vault. Существующие записи не заменяются; исходный файл останется на месте.
        
    
    
        
      
        ВыборИмяТипСостояние
        
    
        
    
        
    
    
        
    
        Поддерживаются однострочные записи KEY=value, кавычки и export. Ссылки на переменные и команды сохраняются как текст. Список действует 5 минут. Доступ сервисам задаётся отдельно кнопкой «Доступ».
        
    
        
  
        
        

  
        
    
        Доступ к записи
        
    
        Разрешение действует только для выбранного сервиса и профиля. Само подключение должно быть разрешено в разделе «Доступ MCP». Обычные команды агента и другие сервисы эту запись автоматически не получают.
        
    
        
    
    
        
      
      
      
    
        
    
        
    
    
        
    
        После изменения записи, профиля или команды сервиса подтвердите доступ заново. Отзыв блокирует следующие вызовы и выдачу ещё не полученного результата. Уже переданное процессу значение и полученные ответы нельзя забрать обратно.
        
    
  
        
        

  
        
    
        Запись Vault
        
    
        
      
      
      
        Для переменной используйте латинские буквы, цифры и подчёркивание; первый символ — буква или подчёркивание. Значение переменной может быть пустым.
