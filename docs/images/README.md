# README images

`architecture.svg` and `architecture.ru.svg` are editable, self-contained vector
overviews of the shared agent path. Their English/Russian layouts match; local
icons and text are drawn directly in SVG, without remote fonts or image assets.
The direct ACP adapter, profile-dependent CLI/Telegram routes, separate desktop
ChatGPT/OpenCode workspaces and optional Linux KVM mode are identified explicitly.
Keep the diagram consistent with the implementation and directory map in the
root READMEs.

`desktop-chat.png` and `desktop-first-run.png` show Igorek desktop 0.1.889 with
synthetic sessions and the Russian interface. The real renderer/HTML/CSS was
used in a separate Electron profile. No personal conversations, account keys or
owner settings were used.

These images illustrate the interface; they do not establish a completed model
task or account consent. Refresh them when the visible interface changes, and
check readability, current behavior and privacy before committing replacements.
Android and Windows images require acceptance of their corresponding builds.
