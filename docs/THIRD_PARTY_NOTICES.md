The vendored browser asset inventory records versions and checksums in
`factory/web_ui/static/vendor/README.txt`. Preserve those notices when packaging
the corresponding assets. Electron distributions include their own `LICENSE`
and `LICENSES.chromium.html`; bundled Python packages retain `.dist-info` notices.

The completion chime at `factory/web_ui/static/audio/task-completed.mp3` is an
original two-tone synthesis generated by `tools/generate_completion_sound.py`.
It uses mathematical waveforms only, without recordings, game audio or samples,
and is covered by the project's Apache-2.0 license. Regenerate it with Python
and FFmpeg/libmp3lame:

```bash
python tools/generate_completion_sound.py \
  --output factory/web_ui/static/audio/task-completed.mp3
```

The terminal rendering modules under `factory/core/tui/` identify upstream
implementations in their source. Python wheels carry the upstream license and
NOTICE in their distribution metadata. Linux snapshots include them under
`licenses/`. Preserve these files when redistributing modified implementations.

Dependency lockfiles identify versions, but are not a license audit. Generated
release archives must be reviewed separately for dependency licenses, native
bindings, fonts, images, audio and optional guest image contents.

Windows desktop payloads include ripgrep 15.1.0 for the Grep tool. Its verified
upstream archive supplies `COPYING`, `LICENSE-MIT` and `UNLICENSE` beside `rg.exe`
under `runtime/tools/`. Preserve those files when redistributing that payload.

entries were found in those resolved JAR/AAR files. The APK carries the full
Apache-2.0 text, the terminal MIT license and OkHttp's public-suffix NOTICE.
Review this inventory again when dependencies change. Permanent signing and
physical acceptance are separate from this notice review.

VM images are not distributed with the current source or desktop releases.
Review their complete distribution notices before introducing an image download.
npm build dependencies are separate from the packaged Electron runtime; review
both inventories when dependencies change. These notices cover the identified
current artifacts and do not clear unrelated historical revisions.
