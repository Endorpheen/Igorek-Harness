!!! info "Последний опубликованный релиз · 0.2.12"
    Предварительная версия добавляет чтение прогресса OpenCode и осьминога из Android в цветах десктопа: в шапке, аватарах помощника, ярлыке и установщике. Названия релизов — на английском; описания и архитектурные схемы доступны на английском и русском. Linux DEB/AppImage и Windows x64 загружаются отдельно от wheel для ручной установки CLI. После обновления backend/инструментов нужно перезапустить обновлённое приложение/runtime, затем чат; работающее подключение к модели заменять не нужно. Android не менялся. См. [релиз 0.2.12](https://github.com/Endorpheen/Igorek-Harness/releases/tag/v0.2.12).
