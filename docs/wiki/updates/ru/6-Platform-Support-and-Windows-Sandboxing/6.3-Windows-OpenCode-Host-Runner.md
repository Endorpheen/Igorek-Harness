!!! info "Текущие возможности платформы · 0.2.12"
    Поручение правит исходный выбранный Git-проект с отключёнными снимками. Основная модель может читать прогресс, но не останавливать работу и не отвечать за владельца. Windows поддерживает команды `cmd.exe` и дочерние процессы x64; PowerShell, процессы x86, сетевые пространства имён Linux, KVM и MCP локальных сервисов на Windows не поддерживаются. Нативная проверка проведена на Windows Server 2025 x64 с синтетическими ответами провайдера. Установщик является предварительной сборкой без подписи; физическая Windows 11 ещё не проверена. См. [релиз](https://github.com/Endorpheen/Igorek-Harness/releases/tag/v0.2.12).
