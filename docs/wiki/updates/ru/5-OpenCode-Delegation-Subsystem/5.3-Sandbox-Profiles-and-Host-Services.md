!!! info "Область поручения · 0.2.12"
    Поручение выдаёт запись в исходный проект вместо подготовки копии рабочего пространства. Его конфигурация переопределяет настройки проекта значением `snapshots: false`. Внутренние ссылки на обычные файлы поддерживаются; Windows отклоняет внешние и каталоговые reparse points. Ручной OpenCode сохраняет отдельную службу, разрешения, навигацию и настройки снимков. MCP локальных сервисов и KVM остаются только на Linux. Прокси профилей не передаёт секреты провайдеров внутрь песочницы. См. [текущую конфигурацию службы](https://github.com/Endorpheen/Igorek-Harness/blob/d0e210bbdb9db152c312dc2d089f0cf4f0b520d9/desktop/opencode-service.cjs) и [конфигурацию поручения](https://github.com/Endorpheen/Igorek-Harness/blob/d0e210bbdb9db152c312dc2d089f0cf4f0b520d9/desktop/opencode-sandbox.py).
