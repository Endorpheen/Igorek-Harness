### Интернет-поиск в Desktop

Откройте **Настройки → Интернет-поиск**, выберите Tavily, Exa или Serper, вставьте ключ и нажмите **Проверить и сохранить**. Проверка выполняет один поисковый запрос и расходует лимит службы. Для возврата к сохранённой службе оставьте поле ключа пустым. Выключение поиска сохраняет ключи. После смены службы начните новую задачу.

Ключи зашифрованы в Desktop-хранилище и не копируются в профили моделей, промпты или окружение команд. Хранилище должно быть открыто; PIN окна настроек блокирует интерфейс отдельно. CLI-хранилище не меняется и автоматически в Desktop не переносится. Секреты `TAVILY_API_KEY`, `EXA_API_KEY` и `SERPER_API_KEY`, созданные или импортированные владельцем, тоже могут использоваться; `IGOREK_SEARCH_PROVIDER` сохраняет явно выбранную службу.

Сейчас этот путь работает в Desktop без KVM-изоляции. Tavily и Exa предоставляют поиск и извлечение текста; Serper — только поиск, страницы можно читать доступными инструментами браузера. Служба выбирается явно: автоматического переключения с расходованием лимита другого аккаунта нет.

Бесплатные лимиты определяет провайдер. На 21.10.2026 [Exa](https://exa.ai/pricing) указывает $10 кредитов ежемесячно без платёжного средства, [Serper](https://serper.dev/) — 2500 стартовых запросов без карты, без обещания ежемесячного возобновления. Актуальный лимит Tavily указан на [странице тарифов](https://www.tavily.com/pricing). Эти условия не означают безлимитный или бессрочный бесплатный доступ.
