!!! warning "Доступ к исходному проекту · 0.2.12"
    Описанный ниже сканер снимков — прежняя вспомогательная функция, а не фильтр новых поручений OpenCode. Новые поручения получают выбранный исходный проект, включая игнорируемые файлы в пределах разрешённого доступа. Храни секреты за пределами проектов, разрешённых агентам. Секреты провайдеров остаются в прокси профилей на хосте; наблюдение исключает исходные входы/выходы инструментов и рассуждения и скрывает распознанные секреты. Эти меры не закрывают доступ к секретам, сохранённым внутри разрешённого проекта. См. [текущие границы делегирования](https://github.com/Endorpheen/Igorek-Harness/blob/d0e210bbdb9db152c312dc2d089f0cf4f0b520d9/docs/architecture/OPENCODE_DELEGATION.md).
