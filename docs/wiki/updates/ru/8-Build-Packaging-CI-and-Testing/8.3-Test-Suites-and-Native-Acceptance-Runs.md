!!! info "Результаты опубликованного релиза · 0.2.12"
    Все 11 проверок релиза прошли. Каждый облачный прогон Python 3.13/3.14 собрал 4905 тестов обоих корней: 4870 успешных, 35 существующих пропусков по ОС/окружению, ноль ошибок/падений и 630 успешных подтестов. Desktop-проверки прошли 369 тестов. Проверки файлов/Vault/нативного OpenCode на Windows прошли 42 теста с тремя пропусками Linux; успешны все девять этапов нативного интерфейса, установка/переустановка и обновление с запуском. Linux прошёл девять нативных этапов, проверки наблюдения и живой панели OpenCode, а также изолированное обновление 0.2.11 → 0.2.12 с сохранением Vault, настроек и предыдущей версии. Ответы провайдера были синтетическими; физическая Windows 11 и KVM не заявлены проверенными. Это зафиксированные результаты релиза, а не автоматически обновляемые счётчики. См. [манифест сборки](https://github.com/Endorpheen/Igorek-Harness/releases/download/v0.2.12/BUILD_MANIFEST.json).
