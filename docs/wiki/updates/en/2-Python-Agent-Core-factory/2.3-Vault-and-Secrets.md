!!! warning "Original-project access · 0.2.12"
    The snapshot scanner described below is a legacy helper, not a filter on new OpenCode assignments. New assignments receive the selected original project, including ignored files reachable under its grant. Keep credentials outside projects granted to agents. Provider secrets remain in the host profile proxy; observation excludes raw tool inputs/outputs and reasoning and redacts recognized secrets. Those protections do not make secrets stored inside a granted project inaccessible. See the [current delegation boundaries](https://github.com/Endorpheen/Igorek-Harness/blob/d0e210bbdb9db152c312dc2d089f0cf4f0b520d9/docs/architecture/OPENCODE_DELEGATION.md).
