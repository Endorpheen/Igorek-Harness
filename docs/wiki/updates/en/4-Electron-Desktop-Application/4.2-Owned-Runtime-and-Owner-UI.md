!!! info "Responsive composer and browser dragging · 0.2.18"
    The message controls wrap according to the available panel width, including while the docked browser is resized. Long profile/model labels shrink with an ellipsis; send, stop, microphone and voice controls remain inside the form.

    `desktop_browser` now supports `drag`: select a current `elements.ref` as `target` and provide `points`, an array of 2–128 `{x, y}` coordinates normalized to 0–1 within that element. `duration_ms` is optional (100–3000, default 500). The tool presses the left mouse button, follows the path and releases it. Two opposite canvas points can draw an ellipse or rectangle with the site's selected shape tool; a longer path supports freehand drawing. Inspect the resulting screenshot before claiming that the requested drawing is complete. Stale, protected, obscured and off-screen targets are rejected. This does not enable arbitrary scripts, local-file navigation or dragging between unrelated elements.

!!! info "Composer profile selection · 0.2.16"
    Click the profile/model button beside the message field to list verified connections and start the selected worker in the **same chat**. History, working directory, draft text and pending attachments remain in place. Switching is refused while the chat or the current worker has pending work. Tool approvals from a previous profile selection are not inherited by the new selection. Locked or unverified connections remain unavailable.

!!! info "First-run model setup can be deferred · 0.2.15"
    After creating or unlocking Vault, choose **Настроить модель позже** (set up the model later) to enter the main window, or **Открыть OpenCode** to open its tab directly. No saved primary model, successful API check, running worker or first task is required. Configure OpenCode providers inside OpenCode. Deferring setup does not complete the primary-model guide, and Vault/interface-lock checks remain enforced.
