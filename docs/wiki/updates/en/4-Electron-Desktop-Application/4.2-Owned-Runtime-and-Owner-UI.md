!!! info "Composer profile selection · 0.2.16"
    Click the profile/model button beside the message field to list verified connections and start the selected worker in the **same chat**. History, working directory, draft text and pending attachments remain in place. Switching is refused while the chat or the current worker has pending work. Tool approvals from a previous profile selection are not inherited by the new selection. Locked or unverified connections remain unavailable.

!!! info "First-run model setup can be deferred · 0.2.15"
    After creating or unlocking Vault, choose **Настроить модель позже** (set up the model later) to enter the main window, or **Открыть OpenCode** to open its tab directly. No saved primary model, successful API check, running worker or first task is required. Configure OpenCode providers inside OpenCode. Deferring setup does not complete the primary-model guide, and Vault/interface-lock checks remain enforced.
