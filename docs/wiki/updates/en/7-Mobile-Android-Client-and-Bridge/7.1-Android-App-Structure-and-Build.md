### Reasoning formatting and completed-task time

Expanded reasoning cards use the existing native Markdown renderer, including syntax-highlighted fenced code, per-block copying and horizontal scrolling. Collapsed cards retain a three-line preview; the header copy action still copies the original complete reasoning. Code is displayed as text and is not executed, including unfinished fences received while streaming.

A completed-task card shows elapsed wall-clock time between execution start and completion when both are known. Queue creation time and individual tool durations are not substituted. Pauses within the same task interval are included. Persisted events restore the value on reopening a chat; optional task metadata `started_at`/`completed_at` can backfill missing events. Missing or reversed timestamps leave the duration absent rather than showing zero.


!!! info "Local model context · Android 0.1.119 (120)"
    The session status card uses the local inference server's configured per-slot context from `/props`, rather than the model catalogue's training maximum. The latest server limit takes precedence over an older task event, so a 64k/128k server restart is reflected when session details refresh. Token occupancy uses the last model request, including its tool/history input; it is not a cumulative task total or a live KV-cache measurement. Unknown usage does not imply an empty context. Cloud catalogue/event fallbacks remain available. Install the Android update and use the matching updated Desktop/backend.

!!! info "Compact model labels · Android 0.1.116 (117)"
    Local filesystem model paths are displayed as filenames in the chat profile picker, composer, new-chat details and agent-history model labels. Long menu model labels use at most two lines. Cloud provider/model identifiers retain their namespaces. This is presentation only: profile identifiers, original model values, stored sessions and request routing are unchanged.

!!! info "Notification-only errors and media changes - Android 0.1.115 (116)"
    System errors and task failure details appear only in the notification center. Its bell is accessible from session lists and connection controls as well as chats. Errors remain in diagnostic history; ordinary progress and confirmation controls are retained.

    Changed videos, audio and images are labeled by media type rather than line additions/deletions. Legacy media line counts are excluded from mixed code/media totals. Media files are not requested or copied as text diffs.

!!! info "Switch executor profiles inside an Android chat"
    Tap the profile/model label beside the message field to choose another verified profile, including one using a different model. The current chat, history, draft and attachments remain. Switching is blocked while sending or while a task is queued, running or awaiting input/approval. The connected desktop runtime must support profile control and its Vault must be unlocked. A standalone bridge without profile control reports that switching is unavailable; it keeps existing chat behavior.

!!! info "Image thumbnails and background reconnects · Android 0.1.112 (113)"
    Selected images appear inside the composer with individual remove buttons. Uploaded-image metadata is retained in user messages, live/queued events and restored history. The app uses the existing authenticated, certificate-pinned upload download route, private cache files and bounded off-thread thumbnail decoding. Non-image files retain their names.

    Only `NET.READ_TIMEOUT` from the event stream (`mobile-events`, `sse_read`, read operation) may remain quiet while the activity is in the background or during its first 15 seconds after returning. The incident remains in diagnostic exports. If the stream has not recovered after that foreground grace period, its warning becomes visible. Authentication, TLS, model, send/write, ordinary foreground and other connection failures retain their notifications.

    Messages with thumbnails omit the redundant legacy attachment line, including restored history. Filenames remain below the previews.
