!!! info "Switching the profile of an idle chat · next desktop update"
    Authenticated `POST /sessions/{session_id}/profile` accepts only a `profile` name. It activates a verified owner-managed connection and updates the existing chat route without replacing its transcript or working directory. The session and executor must have no pending work. Each actual route change starts a new approval generation, so earlier tool grants are not reused, including after switching back. Existing clients and their session creation/message routes remain compatible.
