!!! info "Assignment scope · 0.2.12"
    Assignments now grant the original project for writing rather than preparing a copied workspace. Their configuration overrides project settings with `snapshots: false`. Internal regular file symlinks are supported; Windows rejects external and directory reparse points. Manual OpenCode keeps its separate service, grants, navigation and snapshot settings. Host-services MCP and KVM remain Linux-only. Profile proxying does not transfer provider secrets into the sandbox. See the [current service configuration](https://github.com/Endorpheen/Igorek-Harness/blob/d0e210bbdb9db152c312dc2d089f0cf4f0b520d9/desktop/opencode-service.cjs) and [assignment configuration](https://github.com/Endorpheen/Igorek-Harness/blob/d0e210bbdb9db152c312dc2d089f0cf4f0b520d9/desktop/opencode-sandbox.py).
