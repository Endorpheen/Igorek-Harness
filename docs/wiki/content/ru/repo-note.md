## Назначение
Мультиплатформенный агентный харнесс и настольное приложение на Electron, обеспечивающие безопасную песочницу рабочего пространства, циклы исполнения инструментов LLM и автономные фоновые задачи по программированию. Используется разработчиками для локальной и удаленной разработки с помощью ИИ.

## Ключевые технологии
Python, Node.js, Electron, C++, Microsoft Detours, Bubblewrap, Git

## Структура верхнего уровня
* `factory/`: основное агентное окружение исполнения на Python
* `desktop/`: оболочка настольного приложения на Electron и обработчики IPC
* `desktop/native/`: C++-адаптер каналов Windows и хуки
* `tests/`: наборы интеграционных и платформенных проверок
* `docs/`: журналы релизов и эксплуатационные спецификации
* `pyproject.toml`: конфигурация проекта Python и точки входа

## Ключевые концепции
* OpenCode Assignment: изолированная сессия фоновой задачи по программированию
* WindowsSandbox: изоляция через ограниченный токен Win32 и объект задания
* Vault: зашифрованное локальное хранилище учетных данных пользователя
* Managed Mode: режим настольного приложения с собственным окружением исполнения и строгим разделением
* OpenAI Responses: SSE wire-адаптер для chat completions модели
* Detours Pipe Adapter: DLL на C++, предоставляющая DACL для каналов ограниченных дочерних процессов
* Transit Grants: временные разрешения на каталоги-предки для обхода
* Compaction: реактивное суммирование диалога, предотвращающее выход за пределы контекста
* Steer: внедрение сообщений в реальном времени во время выполнения активной задачи
* AgentRuntime: общий мьютекс исполнения и система управления воркерами
* Synthetic LLM Provider: локальный HTTP SSE-сервер для тестирования протокола
