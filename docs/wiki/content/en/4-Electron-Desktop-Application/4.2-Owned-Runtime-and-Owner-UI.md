## Purpose and Scope
This document covers the technical architecture of the Electron desktop application's managed backend runtime, the owner IPC preload interface, secure vault settings panels, busy-state management, recovery file processing, and browser favorites. The subsystem guarantees that the spawned Python backend runs in a locked-down environment, communicates securely via structured IPC streams, and exposes a strict boundary for administrative owner operations.

Sources: `[desktop/runtime.cjs:1-233](), [desktop/owner-preload.cjs:1-109]()`

## Managed Backend Spawn (`runtime.cjs`)

The Electron main process manages the lifecycle of the Python core via the `OwnedRuntime` class [desktop/runtime.cjs:68-74](). `OwnedRuntime` extends Node's `EventEmitter` and controls spawning, environment isolation, bundle validation, and graceful teardown.

### Bundle Validation and Environment Isolation
Before spawning the Python child process, `loadBundle()` verifies the integrity of the release bundle using a `manifest.json` schema check [desktop/runtime.cjs:63-67](). Path traversals and symlink escapes are prevented by `bundleFile()`, which validates that resolved bundle paths remain strictly contained within the root directory [desktop/runtime.cjs:56-62]().

The environment passed to the Python process is constructed by `runtimeEnvironment()`, which strips inherited host secrets (such as `FACTORY_API_KEY` or `LD_PRELOAD`) and establishes dedicated private paths for `HOME`, XDG directories, and cache locations [desktop/runtime.cjs:15-55](). On Windows, required OS variables like `SystemRoot` and `COMSPEC` are preserved while redirecting user profile data to the isolated runtime directory [desktop/runtime.cjs:24-38]().

## Owner Preload & IPC Surface (`owner-preload.cjs`)

The owner UI communicates with the main process and backend via a secure context bridge defined in `desktop/owner-preload.cjs` [desktop/owner-preload.cjs:1-29](). It exposes the `igorekVault` and `IgorekCompletionSoundSettings` APIs to the renderer world [desktop/owner-preload.cjs:2-86]().

All vault operations (`chatgptBegin`, `unlock`, `saveValue`, etc.) pass through a wrapper `invoke` function that intercepts replies [desktop/owner-preload.cjs:8-18](). If an IPC call returns an error object, `invoke` automatically formats and forwards a notification via `igorek:notifications`, unless the error code is explicitly designated as `operation_busy` [desktop/owner-preload.cjs:11-13]().

Sources: `[desktop/owner-preload.cjs:1-109]()`

## Concurrency & Busy States

When vault modifications or restricted operations overlap with an active agent run, the backend throws an `operation_busy` error (with code `'operation_busy'`) [desktop/tests/owner-busy.test.cjs:40-41](). 

The preload bridge and main process handle busy states distinctly from critical errors:
* **Busy Responses**: When `operation_busy` is returned, it is passed back to the UI without generating an intrusive error notification [desktop/tests/owner-busy.test.cjs:47-54]().
* **Genuine Errors**: Failures like `vault_locked` or backend unavailability trigger automated desktop notifications via `igorek:notifications` [desktop/tests/owner-busy.test.cjs:56-66]().

Sources: `[desktop/tests/owner-busy.test.cjs:1-66](), [desktop/owner-preload.cjs:8-18]()`

## Recovery Files & Browser Favorites

### Recovery Files (`recovery-files.cjs`)
Recovery backups are managed with strict validation checks to prevent directory traversal or symlink attacks. The `readRecovery()` function enforces hard limits:
* Verifies file type and rejects symlinks (`lstat`) [desktop/recovery-files.cjs:6-8]().
* On Windows, recursively validates all parent directories for symlink integrity [desktop/recovery-files.cjs:9-15]().
* Enforces a maximum file size restriction (`MAX_BYTES = 16 * 1024 * 1024`) [desktop/recovery-files.cjs:4]().
* Uses explicit file flags (`constants.O_RDONLY | constants.O_NOFOLLOW`) [desktop/recovery-files.cjs:16]().

Functions like `saveRecovery()` and `restoreRecovery()` securely marshal backup buffers into base64 payloads to communicate with the owner backend process [desktop/recovery-files.cjs:33-54]().

Sources: `[desktop/recovery-files.cjs:1-61]()`

### Browser Favorites (`browser-favorites.cjs`)
The `BrowserFavorites` class manages pinned URLs for the desktop browser UI:
* **Normalization**: Strips trailing slashes, parses schemes, and rejects private/local IPs (`localhost`, `127.0.0.1`, `file://`, `javascript:`) [desktop/tests/browser-favorites.test.cjs:5-9]().
* **Security Permissions**: Automatically enforces strict file permissions (`0o600`) on the persistent JSON store [desktop/tests/browser-favorites.test.cjs:10-14]().
* **Bounds**: Enforces a maximum limit on stored items and prevents updates if storage files are malformed or symlinked [desktop/tests/browser-favorites.test.cjs:15-22]().

Sources: `[desktop/tests/browser-favorites.test.cjs:1-22]()`
